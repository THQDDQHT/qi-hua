# Docker 部署

如果你希望在自己的机器或服务器上运行项目，可以直接使用 Docker Compose。

## 使用发布镜像

```bash
git clone git@github.com:basketikun/infinite-canvas.git
cd infinite-canvas
docker compose up -d
```

启动后访问：

```text
http://localhost:3000
```

## 本地构建镜像

如果需要基于当前源码构建镜像：

```bash
docker compose -f docker-compose.local.yml up -d --build
```

## 文档站镜像

文档站位于 `docs/` 目录，按带服务端能力的 Next.js standalone 应用单独构建，不打进主应用镜像。

使用发布镜像：

```bash
cd docs
docker compose up -d
```

基于当前源码本地构建：

```bash
cd docs
docker compose -f docker-compose.local.yml up -d --build
```

## 数据说明

当前主应用镜像使用 Nginx 提供 Vite 静态文件。画布、我的素材、生成记录和 AI API Key 默认保存在浏览器本地；普通自部署模式的第三方提示词仍由浏览器前端直连拉取。公众部署会把压缩后的提示词封面和清单保存到服务器 `data/prompt-library/`，该目录不进入 Git 或 Docker 镜像，并以只读方式挂载给 Web 容器。
